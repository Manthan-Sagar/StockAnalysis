The Mathematical Anatomy of Information Leakage

When forecasting a forward 5-day return target y[i, t] = Σ (k=1..5) ε[i, t+k], any training row at t_test_start − 1 contains price returns that directly overlap into the test evaluation window:

Train Row at (t − 1): y[t−1] uses prices from t to t+4 (overlaps into Test fold!) Standard TS-Split: Train index touches Test index → INFLATED / LEAKED SHARPE PurgedKFoldEmbargo: Purges h=5 rows before Test start + 1% Embargo buffer after Test end Assertion Proof: pytest tests/test_purged_cv.py → 10/10 Passed (0% overlap verified)
💡
Leakage Prevention Guarantee: The test suite (tests/test_purged_cv.py) programmatically asserts that the intersection of training indices plus forward horizon h and test indices is strictly empty across all fold configurations.

⚠️ The Survivorship Bias Caveat

Our universe uses 98 currently-listed US equities. Equities that were delisted, acquired, or dropped between 2012 and 2024 are excluded, which creates an upward return bias.
